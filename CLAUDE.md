# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A course-schedule generator / study-path planner for Université Laval, commissioned by the director of the *baccalauréat en génie des eaux* (GEX) as a paid mandate.
The whole domain is French: keep domain vocabulary in French (`cours`, `cheminement`, `préalables`, `matière`, `session`, `jalon`) in prose, documentation, and user-facing UI copy.

**Code is English.** All identifiers (variables, functions, types), error messages, and data keys (JSON) are in English — as the test fixtures already do: `title`/`credits`/`prerequisites`/`mandatory`/`rules`, never `titre`/`crédits`/`préalables`/`obligatoires`/`regles`. French domain terms belong in prose and displayed text, not in code or serialized keys.

**Current state: first delivered version** — scraper (étape 1), solver core (étape 2: weekly schedule A, organigramme placement B, rules-coverage verifier) and the full UI (jalons 3–9) are shipped; only preferences (jalon 10) remain.

## Stack and architecture (decided)

Rust throughout, one Cargo workspace — the reasoning behind each choice is in its ADR:

- **`core`** (library) — all domain logic, zero IO/async; compiles to native (scraper, tests) and WASM (UI).
  The ULaval-page parser (`parser/{mod,catalogue,course,program,transcript}.rs`, `ParseError`) lives here, behind a `parser` feature enabled by default.
  `crates/wasm` — the published npm package — opts out with `default-features = false`, so the parser never reaches the JS surface (ADR `2026-08-parseur-dans-core`).
- **`scraper`** (native async binary) — fetch + parse ULaval pages into JSON snapshots; fetching and parsing strictly separated, parser tested against frozen HTML fixtures.
  It re-exports the parser from `core` rather than owning its own copy.
- **`wasm`** (`cdylib` + rlib) — the frontier crate: one orchestration over `core`, plus the pure functions `ui` calls natively (ADR `2026-08-fusion-des-crates-wasm-et-ui-calculations`). The live surface is the **Dioxus worker**'s — `init_snapshot` + `handle_message`, JSON strings both ways, every request answered under its `id` (0 for one nobody owns). Beside it, **frozen**, sits the JavaScript surface of eight functions — `generate_schedule`/`verify_schedule`, `generate_organigramme`/`verify_organigramme`, `admissible_sessions`, `prerequisites_met`, `coverage_report`, `horizon_sessions`, JS objects in and out via `serde-wasm-bindgen`, `schedule.rs` and `questions.rs` existing for them alone: still built, linted and published, but **never a design constraint** — nothing bends for a JavaScript reader any more, `grille-de-cheminement-interactive` included (ADR `2026-08-surface-javascript-plus-une-contrainte`). `courses` is a *parameter* of the pure functions, never read from the input struct — that is what lets both surfaces share one orchestration — and it is optional on the wire, `init_snapshot` filling a cache shared by both (~66 ms of marshalling saved per call, the whole cost of a short one; ADR `2026-08-snapshot-en-cache-dans-le-module-wasm`). The Rust functions are pure and tested natively; the `#[wasm_bindgen]` glue lives in `boundary.rs` under `cfg(all(target_arch = "wasm32", feature = "boundary"))` only — the feature is on by default so no forgotten flag can publish an export-less package, and `ui` links the crate with `default-features = false` since carrying the glue costs it ~800 KB of wasm. `make static` lints it on the wasm target, `make wasm` builds the npm package and `make ui-calc` the same crate into the ui's assets (both need `cargo install wasm-pack`). Verifying an organigramme runs *both* `place` with everything pinned and `coverage_report`; verifying anything with a course left unpinned is an error, never a false verdict (ADR `2026-08-module-wasm-quatre-fonctions-js`).
- **`ui`** (WASM binary) — Dioxus 0.7, client-side rendered. **Whenever Dioxus code is written or understood, first read `.claude/dioxus.md`** (Dioxus 0.7 API reference): 0.7 changed every API — `cx`, `Scope`, and `use_state` are gone; use `use_signal`, `#[component]`, `rsx!`, `Routable`, `use_resource`.
  `make ui` serves it (`dx serve`), `make ui-build` produces the deployed site in `_ui/public` — `--base-path ulaval-generateur-horaire`, since Pages serves a project site under a sub-path and `asset!()` emits absolute URLs, plus `sw.js` copied beside the index so the service worker's scope covers the app (ADR `2026-08-interface-publiee-a-la-racine-de-pages`).
  The program snapshots it ships are **generated** by `crates/ui/build.rs` from whatever `make ui-data` copied: adding a snapshot needs no code change (ADR `2026-08-manifeste-de-programmes-genere`).
  It ships no cheminement, and no longer reads one from a file: the `.json` import/export pair is gone, and with it `crates/ui/src/cheminement.rs` — `data/cheminements/` keeps the hand-written grids but nothing in the UI consumes them. « Partager » (the whole organigramme in a link) is the round trip, the Capsule drawer the way in (ADR `2026-08-retrait-de-l-aller-retour-json-du-cheminement`, superseding `2026-08-un-cheminement-par-fichier` on this point).
  The status strip's « Exporter ▾ » is one menu of two entries — « Organigramme », « Horaire » — each opening its print preview; the menu names no format (ADR `2026-08-menu-d-export-unique`, as amended).
  A student can also import a program the shipped snapshots don't cover, by pasting its ulaval.ca URL: the UI fetches the page through the `corsproxy.io` CORS proxy, since `www.ulaval.ca` sends no CORS header a direct browser fetch could use (ADR `2026-08-import-de-programme-via-proxy-cors`).
  The fetched HTML is parsed in the browser with `core`'s parser, and the resulting program is kept in `localStorage` under `gh.v1.programmes-locaux`, alongside its provenance (source URL, import date, proxy) and any parsing anomalies (ADR `2026-08-programmes-locaux-en-localstorage`).
  A program can also be loaded from a local `{code}-{semestre}.json` file instead of a URL, next to that same import form; it joins `gh.v1.programmes-locaux` the same way, `LocalProgram.origin: ProgramOrigin` (`Url` | `File`) telling the two apart so one type still serves both (ADR `2026-08-import-de-programme-par-fichier-json`).
  A relevé de notes pasted from Capsule's « Relevé de notes non officiel » page (parsed in `core::parser::transcript`, behind the same `parser` feature) fills an open plan's organigramme: passed and in-progress courses pin to their real session, « RECONNAISSANCE DES ACQUIS » credits without one, `Plan.start` and the horizon adjust to match, and the load itself is one undoable act with a bilan of what happened (ADR `2026-08-import-de-releve-capsule`, ADR `2026-08-collage-capsule-en-tiroir-non-bloquant` for the non-blocking drawer it lives in).

To run tests with coverage, use `make test` (wraps `cargo +nightly llvm-cov`, failing under 100 %).
The makefile is the single definition of what CI verifies — `ci.yml` calls `make lint` / `make test` / `make wasm ui-build docs` rather than copying commands (ADR `2026-08-makefile-definition-unique-de-la-ci`).
If it reports <100% on a file whose code all looks tested: inline tests make the file compile twice (unit + integration binary), and llvm-cov scores the **best single compilation, never the union** — 100% requires one compilation to cover the whole file by itself. Diagnose by ventilating `llvm-cov report --json` per crate hash (compare each copy's per-region counters), then fill the cheaper side with an inline test; don't chase it as a tool artifact (ADR `2026-07-couverture-par-instanciation-le-plus-petit-ecart`).

Fully static, serverless: no backend, no database; snapshots produced by a CI cron job (never in-app scraping); the solver runs in the browser; user state in `localStorage`; schedule sharing via URL.
Load-bearing invariants (constraints, not preferences): **all business logic in the pure `core` crate, none in the view**; **never drop unrecognized input silently**; **atomic snapshot replacement**.

## Domain quick facts

- **Session naming & founding hypothesis**: sessions are named season+year (`a2026` = Automne 2026, `h####` = Hiver, `e####` = Été). A future session with no published schedule reuses the most recent offering of the *same season* — per course, via each season's `last_offered` vintage (ADR `2026-07-snapshot-unique-des-cours-millesime-par-saison`); a course page with no session section at all is a new course, kept as offered fall+winter with `last_offered`/`options` both `null` (ADR `2026-07-cours-sans-section-de-session-offert-automne-hiver`).
- **Data files**: `data/cours.json`, one file holding every multi-season `Course` whole, sorted by code (per-course: `code`, `title`, `credits` — a plain number or `{min, max}` for a stage the student weights himself, `cycle`, subject, `prerequisites` raw + parsed tree, contributing programs, `equivalents`, per-season `last_offered` + `options`: each option a *complete* enrolment, so you take one option whole and union its sections' slots; `options: null` = offered but schedule not yet published, distinct from `[]`) — beside the hand-maintained `data/cours.manuel.json` the scraper never writes — which carries both `courses` and `vintages`, the per-admission-vintage prerequisite corrections layered under the student's own `Plan.prereq_overrides` and applied to the `Course` values before the solver reads them (ADR `2026-08-correction-des-prealables-par-millesime`) — and `data/programmes/{code}-{semester}.json` — one file per program *and semester vintage*, where `code` is the **official répertoire code**, read from the page's accordion-button ids, its degree prefix abridged to one letter (`B-GEX`, and `M-GEX` — never `MM-GEX` — for the maîtrise avec mémoire), and `slug` a dedicated field holding the URL's last segment (ADR `2026-08-code-officiel-de-programme-et-slug`; the test-case fixtures are named by code too: `tests/fixtures/test_cases/programs/B-GEX.{html,json}`) — (`semester` is also a field of `core::Program`, a `Semester` serialized `A26`/`H27`/`E27`: the session *following* the scrape — January–April → `E`, May–August → `A`, September–December → next civil year's `H` — so students keep the version they enrolled under; ADR `2026-08-millesime-de-programme-en-semestre`), a bare `core::Program` (`credits_required`, `possible_semester_start` — the page's admission sessions as letters `["A", "H"]` — `mandatory`, `rules`, `concentrations`, `profiles`, `notes` for prose no grammar covers, `language_requirement` for the course-or-test *exigence linguistique* lifted out of the rules/notes) — and `data/cheminements/{code}-{semester}[-{concentration}].json`, one file per cheminement type, the document being the grid alone (`completed`, `sessions`) with the name carrying program, vintage and concentration in snake case; never written by the scraper, and the very shape the UI reads and writes (ADR `2026-08-un-cheminement-par-fichier`). Running `ulaval-scraper program` with no URLs refreshes every program already in the directory (the slug is read from each snapshot's `slug` field, never from the filename — ADR `2026-08-code-officiel-de-programme-et-slug`); it requires `data/cours.json` (fails immediately otherwise) because it appends a computed constraint-less rule « Scolarité préparatoire » listing every 0xxx course transitively reachable from the program's `mandatory` prerequisites — omitted when empty (ADR `2026-08-regle-scolarite-preparatoire`).
- **Scope is decided twice**: the `8xxx` filter in `Catalogue::from_entries` is a shortcut that saves an HTTP request, *not* an exhaustive rule (PSY-7851 is a thesis milestone numbered `7xxx`). The authority is the cycle read on the page — anything above the second cycle, « Études post-MDD » included, yields no course and no anomaly. Préuniversitaire `0xxx` courses are *in* scope (reinstated for préalables préuniversitaires); a course's cycle is `CourseCycle` (`Preuniversity`/`First`/`Second`, serialized `0`/`1`/`2`), distinct from a program's `Cycle` (`First`/`Second`) which can never be préuniversitaire.
- **`matière` = course-code prefix** (`GCI-`, `GEX-`); filtering by subject filters the catalogue URLs, no facet needed.
- **Program mapping comes from course pages** ("Cette activité est contributoire dans :"), not program pages; only programs whose rules are needed get their page scraped.
- **Cheminements types (A1→H8 organigramme) are hand-encoded** — no machine-readable source exists. 26 files under `data/cheminements/` (B-GEX 1, B-GIN 8, B-GMC 17), converted from the JS repo's CSV and verified against them entry by entry; B-GPH has none, its upstream index being a verbatim copy of the B-GMC's. The official grids use tokens that are not sigles (`OPT-ION1`, `AUC-HOIX`, `LAN-GUES`): the catalogue gate refuses them and the bilan names them, never silence.
- **Two parser grammars** (full specs in `docs/conception/`): program rules ("Règle N – \<contrainte\> parmi :" → tagged `{type: course|credits, min, max}` — "Un cours parmi" is min 1, max 1; over-max is a typed error, ADR `2026-08-contrainte-etiquetee-min-max`) and préalables (ET/OU source text → trees keyed `all`/`any` + `program_credits`; a sigle the répertoire stars — « GCI-2010* », « peut être suivi simultanément » — becomes `{"concomitant": "GCI-2010"}`, which the solver satisfies with the *same* session, the bare-string leaf keeping its strict meaning and the global `concomitant` setting demoted to a blanket dérogation — ADR `2026-08-etoile-de-concomitance-au-parsing`; a comma enumeration of sigles is governed by the connector that closes it — « CHM-0150, CHM-0160 OU CHM-0170 » is a OU of three — and forms one operand of the surrounding precedence, a run no connector closes staying raw, ADR `2026-08-virgule-selon-le-connecteur-final`). A grammar change reaches `data/cours.json` through `ulaval-scraper reparse`, which re-derives every tree from the `raw` already stored — no network, no re-scrape. Anything outside a grammar is kept as raw text (`{"raw": "…"}`) and surfaced, never ignored — with three named exceptions: the *exigence linguistique* (ANL-2020/VEPT, FLS-2093/TCF-TP) is parsed into `Program.language_requirement` instead of kept raw (ADR `2026-07-exigence-linguistique-champ-dedie`); "negotiated" rules with no fixed list (*convenus avec la direction*, *requis par la concentration*, passage intégré) are a recognized `RuleCourses` keyword `"negotiated"` — raw kept, but no longer an anomaly (ADR `2026-07-regles-negociees-reconnues`); and the génie bacs' graduation-stage prose is promoted into a « Stages » rule appended after the scraped ones (`{type: course, min: 1, max: 8}`, every sigle of the note in order, whole note kept on the rule, `credits_in_addition: true` since its credits are *en sus* of the total — ADR `2026-08-stage-obligatoire-en-prose-promu-en-regle`).
- **Scraping**: pages are server-rendered, plain GET, no headless browser (2026-07-02 spike); ~10 000 requests for the full catalogue, throttled to ~10 requests/second (~20 min); resume on error; existing snapshots keep being served until the atomic `rename`.
